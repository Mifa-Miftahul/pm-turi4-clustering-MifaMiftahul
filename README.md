## Ringkasan

Praktikum clustering dengan K-Means bertujuan untuk mengelompokkan data pelanggan berdasarkan kemiripan karakteristik tanpa menggunakan label. Fitur yang digunakan meliputi usia, pendapatan, dan skor belanja. Praktikum mencakup proses scaling data, penentuan jumlah cluster menggunakan metode Elbow, penerapan algoritma K-Means, evaluasi menggunakan silhouette score, serta interpretasi hasil clustering.

## Temuan Utama

- K-Means mengelompokkan data pelanggan berdasarkan kemiripan karakteristik tanpa memerlukan label.

- Metode Elbow digunakan untuk membantu menentukan jumlah cluster yang sesuai berdasarkan nilai inertia.

- Scaling membantu menyamakan skala fitur agar fitur dengan rentang nilai besar tidak mendominasi perhitungan jarak.

- Silhouette score digunakan untuk mengevaluasi kualitas cluster, sedangkan profil rata-rata membantu menjelaskan karakteristik setiap kelompok pelanggan.
